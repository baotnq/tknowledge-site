# tknowledge.org

Website giới thiệu và hướng dẫn T-knowledge, chạy trên GitHub Pages. Tách khỏi code server
(`t-knowledge-system`) để sửa trang liên tục mà không phải build hay deploy server.

- `index.html` — trang chủ
- `docs/index.html` — /docs (nối Claude, các loại entry, tool, mã từ chối)
- `privacy/index.html` — /privacy
- `qr-tknowledge.png`, `qr-tknowledge.svg` — QR tới https://tknowledge.org
- `CNAME` — domain của GitHub Pages

Link connector cho Claude: **https://mcp.tknowledge.org/mcp** (server tk, repo `t-knowledge-system`).

Tách từ các trang của tk-api ở commit 333bc8c (11/10/2026). Các giá trị server từng tự điền
(điều khoản kho thử, email liên hệ) giờ là chữ cố định — đổi ở server thì sửa tay ở đây.
